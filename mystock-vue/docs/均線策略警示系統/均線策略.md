## 2. 策略分類與觸發條件

均線策略的核心邏輯分為以下 **四大類六種策略**，每種策略以唯一 `strategy_id` 識別。

### 2.1 突破 / 跌破策略（Cross Over / Cross Under）

#### `price_cross_ma` — K 線突破/跌破關鍵均線

| 屬性 | 說明 |
| :--- | :--- |
| **策略邏輯** | 當日收盤價由下往上（或由上往下）穿過指定均線 |
| **預設監控均線** | 20MA（月線）、60MA（季線）、240MA（年線） |
| **觸發方向** | `cross_above`（突破）/ `cross_under`（跌破） |
| **應用場景** | 突破月線 → 短期轉強買點；突破季線/年線 → 中長期趨勢翻多；跌破月線 → 停損/減碼警示 |

**觸發判定**（虛擬碼）：

```python
# cross_above: 前一日收盤價 < MA 且 當日收盤價 > MA
triggered = (prev_close < prev_ma) and (curr_close > curr_ma)

# cross_under: 前一日收盤價 > MA 且 當日收盤價 < MA
triggered = (prev_close > prev_ma) and (curr_close < curr_ma)
```

#### `ma_golden_death_cross` — 黃金交叉 / 死亡交叉

| 屬性 | 說明 |
| :--- | :--- |
| **策略邏輯** | 短天期均線穿越長天期均線 |
| **預設配對** | 5MA↔20MA、20MA↔60MA、60MA↔240MA |
| **觸發方向** | `golden_cross`（短上穿長）/ `death_cross`（短下穿長） |
| **應用場景** | 趨勢確立訊號。例：60MA 上穿 240MA → 長期牛市啟動 |

---

### 2.2 均線排列與趨勢策略（MA Alignment & Trend）

#### `ma_alignment` — 多頭排列 / 空頭排列

| 屬性 | 說明 |
| :--- | :--- |
| **策略邏輯** | 判斷多條均線是否呈現有序排列 |
| **多頭排列** | `5MA > 10MA > 20MA > 60MA`，且各均線斜率為正（扣抵方向向上） |
| **空頭排列** | `5MA < 10MA < 20MA < 60MA`，且各均線斜率為負 |
| **應用場景** | 多頭排列 → 篩選強勢股（動能策略）；空頭排列 → 持股安全警示，不宜逢低攤平 |
| **觸發時機** | 排列狀態從非有序 → 有序排列的轉換當天觸發 |

---

### 2.3 均線擠壓與爆發策略（MA Squeeze & Breakout）

#### `ma_squeeze_breakout` — 均線糾結突破

| 屬性 | 說明 |
| :--- | :--- |
| **策略邏輯** | 計算 5/10/20/60MA 四條均線的極差佔股價比例，當四線距離縮至門檻以內持續 N 天後，出現大陽線帶量突破最上方均線 |
| **預設參數** | 糾結門檻：極差 < 股價 × 2%；持續天數 ≥ 5 天；突破量 ≥ 5日均量 × 1.5倍 |
| **應用場景** | 捕捉籌碼沉澱後的盤整突破起漲點 |

---

### 2.4 乖離率與回檔策略（Bias & Pullback）

#### `extreme_bias` — 正/負乖離過大

| 屬性 | 說明 |
| :--- | :--- |
| **策略邏輯** | 計算 `BIAS = (收盤價 − MA) / MA × 100%` |
| **預設門檻** | 負乖離 ≤ −15%（超賣）→ 超跌反彈關注；正乖離 ≥ +25%（超買）→ 過熱停利警示 |
| **可設定參數** | 均線週期（預設 60MA 季線）、正/負乖離門檻百分比 |

#### `ma_pullback_support` — 均線回踩測試

| 屬性 | 說明 |
| :--- | :--- |
| **策略邏輯** | 股價處於多頭趨勢中，拉回至月線或季線附近（距離均線 ±1% 範圍內）且未跌破 |
| **前提條件** | 須先滿足多頭排列或收盤價在目標均線之上超過 N 天 |
| **應用場景** | 找尋趨勢股的「拉回買點（Buy the Dips）」 |

## 3. 策略濾網設計（Filter Engine）

為避免純均線策略在盤整期頻繁觸發假訊號（Whipsaw），警示系統支援疊加以下輔助濾網。**濾網為選配**，由策略設定檔中啟用。

| 濾網 ID | 名稱 | 條件說明 | 適用市場 |
| :--- | :--- | :--- | :--- |
| `volume_confirm` | 成交量確認 | 突破當天成交量 ≥ 5日均量 × 1.5 倍 | 台股 / 美股 |
| `institutional_buy` | 籌碼面加持 | 觸發日前 N 天（預設 3 天），三大法人（外資/投信）呈現淨買超 | 僅台股 |
| `market_trend` | 大盤基準過濾 | 僅在大盤指數（加權指數 / SPY）站在 20MA 以上時才觸發買進警示 | 台股 / 美股 |
| `candlestick_confirm` | K 線型態確認 | 突破當天須為陽線（收 > 開），且實體長度 ≥ 振幅 × 50%，排除長上影線假突破 | 台股 / 美股 |

> **設計原則**：濾網只做排除（降低假訊號），不改變策略本身的觸發邏輯。

## 4. 均線參數矩陣

系統預設支援以下均線週期。使用者可透過設定檔自訂。

| 均線代號 | 日線模式天數 | 常用名稱 | 說明 |
| :--- | :--- | :--- | :--- |
| `MA5` | 5 | 週線 | 極短期動能 |
| `MA10` | 10 | 雙週線 | 短期趨勢 |
| `MA20` | 20 | 月線 | 短中期分水嶺 |
| `MA60` | 60 | 季線 | 中期趨勢（法人成本線） |
| `MA120` | 120 | 半年線 | 中長期支撐 |
| `MA240` | 240 | 年線 | 長期趨勢（多空分界） |

> **注意**：日線模式下 MA240 需要至少 240 筆日頻資料。系統在資料不足時應跳過該均線的計算，不可補零。

### 6.1 `GET /api/v1/stocks/{stock_id}/chart-data` — 擴充回應

在現有回應 payload 中新增 `moving_averages` 欄位：

```jsonc
{
  "success": true,
  "data": {
    // ... 既有欄位不變 (dates, kline, institutional, margin, ...)
    "moving_averages": {
      "MA5":   [null, null, null, null, 102.3, 103.1, ...],
      "MA20":  [null, ..., 98.5, 99.2, ...],
      "MA60":  [null, ..., 95.0, 95.3, ...],
      "MA120": [null, ..., 92.1, ...],
      "MA240": [null, ...]
```

## 7. 策略設定檔格式（YAML）

策略以 YAML 設定檔驅動，不將邏輯寫死在程式碼中：

```yaml
# config/strategies.yaml

# 全域預設值
defaults:
  ma_periods: [5, 10, 20, 60, 120, 240]
  volume_ma_period: 5           # 均量計算天數
  scan_frequency: "daily_close" # daily_close | intraday_15m (未來)

strategies:
  # ── 突破 / 跌破策略 ──────────────────────────
  - id: "price_cross_ma"
    name: "收盤價突破/跌破關鍵均線"
    enabled: true
    markets: ["tw", "us"]
    conditions:
      - type: "price_cross"
        target: "close"
        ma_periods: [20, 60, 240]       # 僅監控月/季/年線
        directions: ["cross_above", "cross_under"]
    filters:
      - type: "volume_confirm"
        params: { multiple: 1.5 }
      - type: "candlestick_confirm"
        params: { body_ratio: 0.5 }

  - id: "ma_golden_death_cross"
    name: "均線黃金/死亡交叉"
    enabled: true
    markets: ["tw", "us"]
    conditions:
      - type: "ma_cross"
        pairs:
          - { short: 5, long: 20 }
          - { short: 20, long: 60 }
          - { short: 60, long: 240 }

  # ── 排列策略 ──────────────────────────────────
  - id: "ma_alignment"
    name: "均線多頭/空頭排列"
    enabled: true
    markets: ["tw", "us"]
    conditions:
      - type: "alignment"
        ma_periods: [5, 10, 20, 60]
        require_slope: true               # 需同時判斷斜率方向

  # ── 擠壓突破 ──────────────────────────────────
  - id: "ma_squeeze_breakout"
    name: "均線糾結突破"
    enabled: true
    markets: ["tw", "us"]
    conditions:
      - type: "squeeze_breakout"
        ma_periods: [5, 10, 20, 60]
        squeeze_threshold: 0.02           # 極差 < 股價 × 2%
        squeeze_min_days: 5
    filters:
      - type: "volume_confirm"
        params: { multiple: 1.5 }

  # ── 乖離率 ──────────────────────────────────
  - id: "extreme_bias"
    name: "乖離率過大警示"
    enabled: true
    markets: ["tw", "us"]
    conditions:
      - type: "bias"
        ma_period: 60
        overbought_threshold: 25          # 正乖離 ≥ 25% → 超買
        oversold_threshold: -15           # 負乖離 ≤ −15% → 超賣

  # ── 回踩測試 ──────────────────────────────────
  - id: "ma_pullback_support"
    name: "均線回踩支撐"
    enabled: true
    markets: ["tw", "us"]
    conditions:
      - type: "pullback"
        ma_periods: [20, 60]
        proximity_percent: 1.0            # 距離均線 ±1%
        trend_lookback_days: 20           # 過去 N 天須在均線之上

# ── 僅台股可用的濾網 ──────────────────────────
filters_registry:
  - id: "institutional_buy"
    name: "法人買超濾網"
    markets: ["tw"]
    params:
      lookback_days: 3
      require: "foreign_or_trust_net_buy"
```

## 8. 警示通知機制

### 8.1 觸發頻率

| 模式 | 執行時機 | 優先級 |
| :--- | :--- | :--- |
| **盤後掃描**（Phase 4a） | 每日收盤資料更新後自動執行 | **本次實作** |
| **盤中即時**（Phase 4b） | 盤中每 5–15 分鐘抓取即時行情掃描 | 未來擴充 |

### 8.2 通知訊息範本

**Telegram / LINE 格式**：

```
🚨 【策略觸發 — 強勢突破】
━━━━━━━━━━━━━━━
📌 標的：2330 台積電
📊 條件：收盤價突破 60日季線
💰 收盤價：$1,020（+3.5%）
📈 季線值：$985.5（乖離 +3.5%）
📦 成交量：42,500 張（5日均量 1.8×）
🏦 籌碼：外資連買 3 天
━━━━━━━━━━━━━━━
💡 建議：可納入多頭觀察清單
   停損參考：季線下 3%（$956）
```

### 8.3 訊號強度分級

| 等級 | 定義 | 範例 |
| :--- | :--- | :--- |
| `strong` | 核心策略觸發 + 通過 ≥ 2 項濾網 | 突破季線 + 帶量 + 法人買超 |
| `moderate` | 核心策略觸發 + 通過 1 項濾網 | 突破月線 + 帶量（但法人未買超） |
| `weak` | 核心策略觸發但未通過任何濾網 | 純均線突破、量能不足 |

### 9.2 K 線圖增強

- 在 K 線圖上以圖標（marker）標記策略觸發點位
  - 突破 → 向上箭頭（▲）綠色
  - 跌破 → 向下箭頭（▼）紅色
  - 黃金交叉 / 死亡交叉 → 圓點標記
- 均線改由後端提供數值（取代目前前端即時計算），確保一致性
- 增加 MA120（半年線）、MA240（年線）可選顯示

## 11. 驗收標準

### 功能驗收

| 編號 | 驗收項目 | 通過條件 |
| :--- | :--- | :--- |
| AC-1 | 後端 SMA 計算正確性 | 5/20/60/120/240 期 SMA 與手動 Excel 計算結果誤差 < 0.01 |
| AC-2 | `price_cross_ma` 觸發 | 以 2330 歷史資料驗證，突破/跌破 60MA 時正確產生警示事件 |
| AC-3 | `ma_golden_death_cross` 觸發 | 20MA 穿越 60MA 時正確觸發黃金/死亡交叉事件 |
| AC-4 | 濾網正確排除 | 啟用 `volume_confirm` 後，量能不足的突破事件被過濾 |
| AC-5 | 美股策略可用 | AAPL/TSLA 等美股標的可正確計算均線並觸發策略 |
| AC-6 | API 回應正確 | `chart-data` 新增 `moving_averages` 欄位，`/alerts` 回應符合契約規格 |
| AC-7 | 設定檔驅動 | 修改 `strategies.yaml` 中的參數後，無需改程式碼即可生效 |

### 非功能驗收

| 編號 | 驗收項目 | 通過條件 |
| :--- | :--- | :--- |
