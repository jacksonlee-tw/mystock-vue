# 賣股策略與爬蟲開發

此文件已整理並拆分為兩份主題文件，方便後續維護與擴寫：

- 賣股策略整理：賣股策略.md
- 爬蟲與資料管線整理：爬蟲開發.md

## 文件分工

### 1. 賣股策略.md

聚焦出場邏輯本身，包含：

- 技術面策略
- 籌碼面策略
- 風控與停利停損規則
- 基本面惡化條件
- 可配置的策略欄位建議

### 2. 爬蟲開發.md

聚焦資料供應鏈，包含：

- 需要抓取的資料來源
- Provider 抽象設計
- JSON 落地與資料庫匯入流程
- Docker 排程執行方式
- 防爬與例外處理注意事項

## 建議閱讀順序

1. 先閱讀賣股策略.md，確認出場規則與所需欄位。
2. 再閱讀爬蟲開發.md，確認資料如何取得、落地與排程。
3. 最後再依策略欄位回推資料庫 schema 與回測模組需求。
