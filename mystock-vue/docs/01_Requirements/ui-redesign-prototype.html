優化方案

現況的問題

  • 兩個個股切換器。頂部列一個 select，頁內標題卡再一個，同時出現在同一視窗。
  • 控制列超載。單一張卡片裡塞了 13 個互動元素，且把「管理追蹤清單」和「調整分析視角」兩種不同性質的動作混在一起。
  • 日期區間重複八次。同一串字在標題、分頁列與六張圖卡上各印一次。
  • 顏色不承載資訊。六張圖用六種色（primary／紅／青／粉／綠／橘）＋四顆彩色圓球，純裝飾；紅綠同時被拿去當裝飾色與漲跌語意色。
  • 紅漲綠跌寫死。text-red-500 直接寫在元件裡，美股情境無法反轉。
  • 單位寫死。$／張／萬元 全部硬編碼，美股不適用。
  • 狀態沒進網址。setPeriod()／setMonths() 只改 ref，不寫回 query，重整即掉、連結無法分享。
  • 方向鍵被全域攔截。頂部列綁 ArrowUp／Down 切股並 preventDefault()，使用者無法用方向鍵捲動頁面。

調整後

  • 單一切換入口。Ctrl／⌘ K 全域搜尋，結果依市場分組，支援代號與名稱模糊比對；頁內下拉移除。
  • 動作分層。身分列只放「看什麼／看哪段」；新增與移除追蹤回到 /stocks 管理頁，頁內僅保留一顆 ★ 切換。
  • 區間單一來源。只在主圖工具列顯示一次。
  • 色彩配額。強調色（brass）只用於互動與品牌，紅／綠專屬漲跌與買賣超，其餘一律灰階。
  • 漲跌色由市場決定。--up／--down 兩個 CSS 變數，[data-market] 交換角色，可再由使用者偏好覆寫。
  • 格式化集中。formatPrice/formatVolume(value, market) 單一出口，含幣別、量單位與時區。
  • 狀態即網址。/stock/:market/:symbol?period=&range=&tab=，可重整、可分享、可回上一頁。
  • 快捷鍵讓位。切股改用 [ ]，方向鍵歸還給頁面捲動。

不支援的指標一律不渲染，而不是渲染成空白或 0——空白格會被讀成「這檔沒有法人買賣超」， 而不是「這個市場沒有這種資料」。分頁底部保留一行說明，點開才展開。

建議落地順序

先做（不需後端配合）

  • 抽出 --up／--down 變數，清掉元件內的 text-red-500／text-emerald-500。
  • 移除頁內第二個個股下拉；追蹤管理搬到 /stocks。
  • period／range／tab 寫回 URL query。
  • 刪掉六張圖卡上的重複日期徽章與彩色圓球 icon。
  • 解除方向鍵全域攔截；alert/confirm 換成 Toast／Dialog。

接著做（需後端定義 market）

  • /stocks 回傳新增 market、currency、exchange、lot_size。
  • 路由改 /stock/:market/:symbol，舊網址 301 導向。
  • 建立 metric registry，KPI 與分頁由設定驅動而非寫死。
  • chart-data 依 market 回傳對應 metric 群組與其 frequency。
  • Ctrl K 搜尋改打後端 /search?q=，跨市場分組。
