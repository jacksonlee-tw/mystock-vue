估值歷史深度 — P1 的阻塞項
§6 / ADR-RL-04
目前 62 交易日（約 3 個月） P1 需求 720 交易日（約 3 年）
達成率 8.6% —— 分位數（河流圖）條件 valuation_percentile 尚不可用
P1 目前不可行。估值只有 3 個月，硬做分位數只會得到「近 3 個月的分位數」—— 那是雜訊，不是估值河流圖。P0 先以絕對門檻上線（ADR-RL-04）。
另一層限制：scanner.py 的全市場預載視窗固定為 end_date − 120 天。 即使 DB 有 3 年歷史，ScanContext.valuation 也只看得到 120 天 —— 分位門檻須由 MarketRepository 另一條路徑算好帶入（§5.3）。

pe_max: 15 對金融、傳產寬鬆，對半導體、生技幾乎不可能成立 → P0 名單必然偏向低估值產業。可接受、但需在上線後觀察 30 日名單再決定是否依產業分層（開放問題 Q-1）。
