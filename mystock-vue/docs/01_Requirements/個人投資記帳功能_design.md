針對使用 **FastAPI + Vue** 架構開發的個人股票投資系統，為您規劃「個人投資記帳與績效追蹤模組」的功能清單。

清單分為後端資料處理邏輯與前端互動頁面需求，方便您後續進行 API 設計與 UI 組件拆解：

---

## 一、 交易紀錄管理模組 (Transaction Management)

* **買賣交易明細登錄**
* 新增交易紀錄（股票代碼/名稱、交易類型［買進/賣出/零股］、單價、股數、交易日期時間）。
* 自動計算預設費用：券商手續費（可設定折讓）、證券交易稅（賣出時）。
* 手動調整欄位：允許自訂實際手續費金額與微調稅金。


* **歷史交易列表與維護**
* 交易歷史紀錄表單（支援日期區間、股票代碼、買賣類型篩選與排序）。
* 單筆交易紀錄編輯與刪除（自動更新後續持股與成本計算）。
* 批次匯入/匯出功能（支援 CSV/Excel 格式範本）。



---

## 二、 持庫與未實現損益模組 (Portfolio & Unrealized P&L)

* **即時持庫總覽 (Current Portfolio)**
* 現有持股明細表（持股數量、平均庫存成本、當前市值）。
* 持股成本計算邏輯（支援「先進先出法 FIFO」或「加權平均法」選項）。


* **未實現損益統計**
* 個股未實現損益金額與未實現報酬率（%）。
* 整體持股未實現總損益與總投資報酬率。


* **資產配置分析數據**
* 個股佔持股總市值之權重比例（用於提供前端渲染圓餅圖數據）。



---

## 三、 已實現損益與整體績效模組 (Realized P&L & Performance)

* **已實現損益計算 (Realized P&L)**
* 賣出平倉紀錄自動對沖與已實現損益計算（扣除買賣雙邊手續費與證券交易稅）。
* 平倉明細對照（清楚呈現「該筆賣出對應到哪幾筆歷史買進」）。


* **投資績效與勝率統計**
* 歷史累積已實現總損益（總獲利金額 / 總虧損金額）。
* 勝率統計（獲利交易次數 / 總平倉次數）。
* 平均盈虧比（平均獲利金額 vs 平均虧損金額）。


* **時間區間績效分析**
* 月度 / 年度已實現損益彙整表。
* 資產權益曲線（Equity Curve）與累計報酬率變動趨勢數據。



---

## 四、 現金流與股利管理模組 (Cash Flow & Dividends)

* **除權息與股息紀錄**
* 現金股利（配息）與股票股利（配股）領取紀錄登記。
* 自動將現金股利納入已實現收益與降低持股成本計算法。


* **資金出入金管理 (Cash Management)**
* 本金投入（入金）與獲利提領（出金）紀錄。
* 真實回報率計算基礎：支援計算 **時間加權報酬率 (TWR)** 或 **內部報酬率 (IRR)**，避免因大幅入金/出金扭曲實際操作績效。



---

## 五、 後端 (FastAPI) 與前端 (Vue) 系統介面規劃

| 模組名稱 | FastAPI 後端 API 規劃 | Vue 前端頁面 / 組件規劃 |
| --- | --- | --- |
| **交易紀錄** | `GET/POST/PUT/DELETE /api/v1/transactions` | 交易紀錄流水帳清單表單、新增交易 Modal 彈窗 |
| **庫存管理** | `GET /api/v1/portfolio/holdings`<br>

<br>`GET /api/v1/portfolio/summary` | 當前持股卡片/表格、資產配置圓餅圖 (ECharts/Chart.js) |
| **已實現績效** | `GET /api/v1/performance/realized`<br>

<br>`GET /api/v1/performance/history` | 歷史戰績儀表板、月度損益柱狀圖、勝率指標卡片 |
| **現金流/股利** | `GET/POST /api/v1/dividends`<br>

<br>`GET/POST /api/v1/cashflow` | 股息收入統計表、本金出入金紀錄明細 |
