## 1. 目的與範圍

### 1.1 目的
將「每日盤後自動化選股與市場掃描引擎」完全納入本系統的《策略架構》中。選股功能本質上就是執行特定的策略（例如「基本面+籌碼面共振」），因此不應獨立開發一套選股邏輯，而是擴充底層爬蟲資料源，並將選股條件寫成《策略架構》所支援的 `@condition` 進行掃描。

### 1.2 範圍

| 範圍內 | 範圍外（本階段不做） |
|---|---|
| **爬蟲層擴充**：抓取每日價值指標 (PE/PB/Yield)、營收等 | 盤中即時選股（維持 `daily_close` 頻率） |
| **`ScanContext` 擴充**：加入基本面與籌碼面新欄位 | 複雜財報深度分析（如自由現金流折現估值） |
| **選股條件註冊**：實作基本面、價值面、籌碼面的 `@condition` | |
| **策略 YAML 設定**：定義選股策略組合 | |
| **前端戰情室擴充**：於 Dashboard 呈現選股結果清單 | |

## 2. 現況盤點與架構整合評估

依據《策略架構》的設計，策略定義、資料供應與執行引擎必須解耦。

| 架構元件 | 選股功能整合方式 | 說明 |
|---|---|---|
| **Condition Registry** | 註冊新的條件函式，如 `value_filter`, `chip_resonance` | 完全相容，選股條件本質就是策略條件。 |
| **ChipDataProvider** | 擴充抓取來源，將 PE、PB、殖利率、月營收等欄位載入 `ScanContext` | 資料提供層必須擴充，才能餵給選股策略。 |
| **策略執行引擎 (Scanner)**| 直接沿用，不需修改核心 | YAML 設定好的選股策略，引擎會自動掃描並產出 `ALERT_EVENT`。 |
| **YAML 設定檔** | 新增 `category: "stock_picking"` 的策略 | 利用現有的 YAML 機制動態微調選股門檻。 |

## 3. 爬蟲資料來源與每日抓取項目 (Data Acquisition)

為了支援選股功能，`ChipDataProvider` 需整合以下每日/每月爬蟲排程，將數據落地至 Staging Area (JSON/Postgres)。

### 3.1 台灣證券交易所 (TWSE) / 櫃買中心 (TPEX)
這是最主要且最準確的官方數據來源，每日必抓項目包含：
* **每日收盤行情 (OHLCV)**：既有項目。
* **個股每日價值指標 (BWIBBU)**：抓取每日更新的 **本益比 (PE Ratio)**、**殖利率 (Dividend Yield)**、**股價淨值比 (PB Ratio)**。
* **三大法人買賣超**：抓取外資、投信、自營商每日對各股的買賣超張數及金額。
* **融資融券餘額 (信用交易)**：抓取每日散戶與主力的信用交易動態。
* **全市場市值排名**：用於界定當日台股前 50 大或 100 大權值股。

### 3.2 公開資訊觀測站 (MOPS)
* **每月營收公告**：於每月 10 號前抓取各家上市櫃公司上月營收表現 (MoM, YoY)。

## 4. 資料供應層整合 (`ScanContext` 擴充)

擴充 `backend/services/chip_provider.py`，將爬蟲取得的數據放入上下文。

```python
@dataclass
class ScanContext:
    # ... 既有欄位 (OHLCV, ma, bias 等)
    
    # 價值面指標 (單一數值，因選股通常只看當下或近期)
    pe_ratio: Optional[float] = None
    pb_ratio: Optional[float] = None
    dividend_yield: Optional[float] = None
    
    # 基本面營收 (陣列或最近一期數值)
    revenue_mom: Optional[float] = None
    revenue_yoy: Optional[float] = None
    
    # 籌碼面
    institutional_net_buy: Dict[str, List[float]] = field(default_factory=dict) # {"foreign": [...], "trust": [...]}
```

## 6. YAML 策略設定範例

整合至 `strategy_config/strategies.yaml` 中，不需動程式碼即可動態調整選股邏輯。

```yaml
  - id: "value_and_chip_picking"
    name: "高殖利率與法人共振選股"
    category: "stock_picking"
    enabled: true
    markets: ["tw"]
    cooldown_days: 5
    conditions:
      - type: "value_filter"
        max_pe: 15
        min_yield: 5.0
      - type: "chip_resonance"
        lookback_days: 3
        required_buyers: ["foreign", "trust"]
    filters:
      - type: "volume_confirm"
        params: { multiple: 1.5 }
```

## 7. 前端規格與輸出

### 7.1 戰情室選股雷達 (Vue Dashboard)
* **API 串接**：沿用 `GET /api/v1/strategies/alerts`，並傳入參數 `category=stock_picking` 來過濾出選股結果。
* **介面呈現**：在 `AlertDashboard.vue` 或是新增的 `StockPicking.vue` 中，以表格呈現當日符合條件的個股清單。
* **資料欄位**：除了股票代號與名稱外，需將 `details` 中的觸發數值（如當時的 PE、殖利率、買超張數）展開顯示以利投資人判讀。
