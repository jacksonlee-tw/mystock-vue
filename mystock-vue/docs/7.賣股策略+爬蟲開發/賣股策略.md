# 賣股策略整理

本文件整理原始討論內容中與出場規則直接相關的部分，目的是把策略定義、觸發條件與資料需求收斂成可落地的規格。

## 策略總覽

| 策略類型 | 核心邏輯 | 主要參考數據 | 適用情境 |
| --- | --- | --- | --- |
| 技術面破線 | 趨勢由多翻空，優先保護既有獲利 | 均線、乖離率、成交量 | 波段順勢、動能交易 |
| 籌碼面鬆動 | 主力或法人出貨，籌碼由強轉弱 | 三大法人買賣超、融資融券 | 權值股、投信作帳股 |
| 風控與紀律 | 固定化停損停利與持有期限 | 進場價、最高價、持有天數 | 抄底、短中波段、自動化交易 |
| 基本面惡化 | 原始投資邏輯失效，重新評價持股 | 營收 YoY、EPS、估值區間 | 中長線投資、基本面波段 |

## 一、技術面賣出策略

### 1. 關鍵均線跌破

- 策略邏輯：股價收盤由上往下跌破重要均線，例如 20MA 或 60MA，視為趨勢轉弱。
- 參考數據：日 K 收盤價、20MA、60MA、成交量。
- 觸發建議：
  - 當股價收盤由上往下穿越重要支撐均線（如跌破 20MA 月線），視為短期趨勢轉弱，應觸發停損或減碼警示。
  - 跌破 60MA (季線) 則視為中期趨勢轉弱，可列為較強烈的出場訊號。

### 2. 正乖離過大停利

- 策略邏輯：股價短線急漲，與季線的正乖離率過高，容易引發獲利回吐。
- 參考數據：即時股價、60MA 或季線、乖離率。
- 觸發建議：正乖離率超過 20% 到 25% 可視為過熱區，搭配爆量或長上影線更具參考價值。

### 3. 空頭排列成型

- 策略邏輯：5MA < 10MA < 20MA < 60MA，代表均線結構轉空。
- 參考數據：多天期均線值與斜率。
- 觸發建議：若均線空頭排列成立且價格反彈無法站回短均線，可列為全面出場條件。
- 實戰應用：此為嚴格的安全警示，絕不宜逢低攤平，應考慮全數出場。

## 二、籌碼面賣出策略

### 1. 高檔出貨警示

- 策略邏輯：股價位於高檔區間，法人連續賣超，但融資餘額持續增加，代表散戶接手風險上升。
- 參考數據：三大法人買賣超、融資餘額、區間高點位置。
- 觸發建議：連續 3 日法人賣超且融資增加，可先列為減碼警示。
- 實戰應用：代表強勢手(大戶)出脫，散戶(融資)接刀，這是標準的籌碼渙散敗象，應嚴格執行停利或停損。

### 2. 法人連續結帳

- 策略邏輯：外資或投信由連買轉連賣，代表主導籌碼鬆動。
- 參考數據：外資買賣超、投信買賣超、成交量占比、10MA。
- 觸發建議：
  - **外資認養的大型權值股**：觀察外資連續 3 天由買轉賣的大額倒貨，即觸發減碼警示。
  - **投信作帳的中小型股**：若投信轉賣結帳，或股價跌破 10MA，必須立刻無條件停損。

## 三、風控與紀律策略

### 1. 雙重絕對停損

- 策略邏輯：同時加入價格停損與時間停損，避免高風險進場後拖延處理。
- 參考數據：進場當日最低價、T+1/T+2 收盤價、持有天數。
- 觸發建議：
  - **價格停損**：T+1 或 T+2 日的收盤價低於進場當日的最低價。
  - **時間停損**：買入後 3 個交易日內未出現預期反彈，強制市價平倉。主要針對高風險的極端抄底策略。

### 2. 固定停損與固定停利

- 策略邏輯：進場前先定義損益界線，避免臨場受情緒影響。
- 參考數據：進場均價、現價、報酬率。
- 觸發建議：例如固定停損 -5%，固定停利 +15%。

### 3. 移動停利

- 策略邏輯：價格創高後，容許一定幅度回落，以保留波段空間並守住獲利。
- 參考數據：持倉期間最高價、最新收盤價、回撤幅度。
- 觸發建議：自歷史最高點回落一定幅度 (例如 10%) 即強制結帳出場。
- 實戰應用：針對大波段行情，保證獲利不回吐。

## 四、基本面惡化策略

### 1. 成長動能衰竭

- 策略邏輯：如果是以成長股邏輯買進，當營收或獲利成長失速，原始持有理由即消失。
- 參考數據：月營收 YoY、季 EPS、法人預估差異。
- 觸發建議：連續 2 個月營收 YoY 轉負，或 EPS 顯著低於預期。
- 實戰應用：例如台股每月 10 號前會公布上個月的營收，這是一個敏銳的先行指標。如果一家公司營收 YoY 連續兩個月轉負，即使股價還在高檔震盪未跌破均線，系統也應該立刻發出「基本面轉弱」的減碼預警，避免後續季報開出利空。

### 2. 估值過高均值回歸

- 策略邏輯：好公司若處於過度樂觀估值，後續容易面臨修正。
- 參考數據：P/E、P/B、歷史估值分位數。
- 觸發建議：當估值逼近歷史高分位，且技術面同步轉弱，可列為高優先級停利訊號。
- 實戰應用：當股價因為題材熱炒而大漲，導致本益比 (P/E) 突破歷史河流圖極端上緣 (例如 95% 分位數)，代表股價可能透支未來成長。此時若日 K 線同時爆量收黑或跌破 10MA，就是「基本面過熱 + 技術面轉弱」的最精準停利點。

## 策略實作優先順序建議

若要先做最容易落地的第一版，建議順序如下：

1. 固定停損與移動停利
2. 關鍵均線跌破
3. 法人連續結帳
4. 營收 YoY 惡化

原因是前兩者只依賴價格資料，實作與回測門檻最低；後兩者才需要額外的籌碼與基本面資料來源。

## 系統實作預演 (YAML 設定檔)
為了讓 Python 分析系統能自動化追蹤，可以將條件抽離出來寫入 `config/strategies.yaml` 中，方便未來彈性微調：

```yaml
strategies:
  - id: fundamental_decay_exit
    name: 營收衰退出場
    category: fundamental
    risk_level: warning
    enabled: true
    conditions:
      - type: revenue_yoy
        operator: <
        value: 0
        consecutive_months: 2
      - type: eps_surprise
        operator: <
        value: -10.0
```

## 與爬蟲模組的對接需求 (Data Provider)

要讓上述策略可運算，資料層至少要提供以下欄位：

- 價格類：date、open、high、low、close、volume
- 技術指標類：ma5、ma10、ma20、ma60、bias
- 籌碼類：foreign_net_buy、investment_trust_net_buy、margin_balance、short_balance
- 基本面類：monthly_revenue_yoy、eps、pe_ratio、pb_ratio

策略文件定義的是規則，資料如何取得與排程，請參考爬蟲開發.md。
