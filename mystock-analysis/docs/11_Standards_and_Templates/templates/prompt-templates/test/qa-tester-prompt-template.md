## 📝 Prompt 詳細內容

### 🆔 P001 - 測試案例自動生成

**分類**: 測試案例  
**優先級**: 高  
**適用場景**: 需要根據功能需求快速生成完整測試案例時使用

#### Prompt 內容:
```
你是資深的QA測試工程師。
請根據以下功能需求生成完整的測試案例：

**功能名稱**: [功能名稱]
**功能描述**: [詳細功能描述]
**輸入參數**: [輸入參數說明]
**預期輸出**: [預期輸出結果]
**業務規則**: [相關業務邏輯規則]

請按照以下格式產出測試案例：
1. 測試案例編號
2. 測試案例名稱
3. 測試目標
4. 前置條件
5. 測試步驟
6. 測試資料
7. 預期結果
8. 優先級(高/中/低)

請涵蓋以下測試類型：
- 正向測試案例(正常流程)
- 負向測試案例(異常處理)
- 邊界值測試
- 等價類測試
- 整合測試案例(如適用)
```

#### 使用說明:
- 將`[功能名稱]`替換為實際要測試的功能名稱
- 將`[詳細功能描述]`替換為完整的功能說明
- 將其他參數替換為實際的需求資訊
- 可根據功能複雜度調整測試案例的詳細程度

#### 預期輸出:
- 產生結構化的測試案例集合
- 涵蓋多種測試情境和類型
- 包含完整的測試步驟和驗證標準
- 符合測試案例撰寫最佳實務

#### 相關標籤:
`#測試案例` `#功能測試` `#邊界值測試` `#負向測試`
