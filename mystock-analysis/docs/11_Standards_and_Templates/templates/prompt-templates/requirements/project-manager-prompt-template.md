## 📋 文件說明
本文件收集WEB系統專案經理與系統分析人員在使用AI工具進行專案管理與系統分析時的常用prompt，涵蓋需求分析、專案規劃、系統設計、文件撰寫、風險管理、溝通協調等各個環節。

## 🏷️ Prompt 分類
- **需求分析**: 需求收集、分析、驗證、變更管理
- **專案管理**: 專案規劃、進度控制、資源管理
- **系統設計**: 系統架構、流程設計、資料庫設計
- **文件撰寫**: 規格書、使用手冊、測試計畫
- **風險管理**: 風險識別、評估、應對策略
- **溝通協調**: 會議記錄、報告生成、利害關係人管理

## 📝 Prompt 詳細內容

### 🆔 P001 - 功能需求規格書生成

**分類**: 需求分析  
**優先級**: 高  
**適用場景**: 需要將使用者需求轉換為詳細功能規格書時使用

#### Prompt 內容:
```
你是資深的系統分析師。
請根據以下資訊生成完整的功能需求規格書：

**專案背景**: [專案背景說明]
**使用者需求**: [原始使用者需求]
**系統類型**: [WEB系統/行動應用/其他]

請按照以下格式產出：
1. 功能概述
2. 使用者角色定義
3. 功能需求清單
   - 功能編號
   - 功能名稱
   - 功能描述
   - 優先級(高/中/低)
   - 驗收標準
4. 非功能需求
   - 效能需求
   - 安全需求
   - 使用性需求
5. 使用案例圖(Mermaid格式)
6. 資料流程圖(Mermaid格式)
7. 介面規格說明
```

#### 使用說明:
- 將`[專案背景說明]`替換為實際專案背景
- 將`[原始使用者需求]`替換為從使用者收集到的需求
- 將`[系統類型]`指定為具體的系統類型
- 可根據專案複雜度調整輸出詳細程度

#### 預期輸出:
- 產生結構化的功能需求規格書
- 包含完整的需求分析結果
- 提供可視化的系統分析圖表
- 符合軟體工程文件標準

#### 相關標籤:
`#需求分析` `#功能規格` `#使用案例` `#系統分析`

## 🔄 使用指南

### 快速開始
1. 根據工作需求從清單表中選擇合適的prompt
2. 複製對應的prompt內容
3. 根據實際專案情況調整參數
4. 在AI工具中執行prompt
