## 📝 Prompt 詳細內容

### 🆔 P001 - 使用者旅程地圖生成

**分類**: 使用者研究  
**優先級**: 高  
**適用場景**: 需要分析使用者行為並建立完整旅程地圖時使用

#### Prompt 內容:
```
你是資深的UX設計師。
請根據以下資訊生成完整的使用者旅程地圖：

**目標使用者**: [使用者類型描述]
**使用場景**: [具體使用情境]
**產品/服務**: [產品或服務名稱]
**業務目標**: [企業希望達成的目標]
**痛點假設**: [預期的使用者痛點]

請按照以下格式產出使用者旅程地圖：
1. 使用者畫像
   - 基本資訊
   - 需求與目標
   - 行為特徵
2. 旅程階段
   - 認知階段
   - 考慮階段
   - 決策階段
   - 使用階段
   - 推薦階段
3. 每個階段包含：
   - 使用者行為
   - 思考內容
   - 情緒變化
   - 接觸點
   - 痛點與機會點
4. 改善建議
5. 設計機會點識別
```

#### 使用說明:
- 將`[使用者類型描述]`替換為實際的目標使用者資訊
- 將`[具體使用情境]`替換為真實的使用場景
- 將其他參數替換為實際的專案資訊
- 可根據產品複雜度調整旅程階段的詳細程度

#### 預期輸出:
- 產生結構化的使用者旅程地圖
- 識別關鍵的痛點和機會點
- 提供具體的設計改善建議
- 符合UX設計方法論和最佳實務

#### 相關標籤:
`#使用者旅程` `#UX設計` `#使用者研究` `#痛點分析`

2. 複製對應的prompt內容
