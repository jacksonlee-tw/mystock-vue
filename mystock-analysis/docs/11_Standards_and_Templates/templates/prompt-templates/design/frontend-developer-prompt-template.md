## 📝 Prompt 詳細內容

### 🆔 P001 - Vue組件生成

**分類**: 組件開發  
**優先級**: 高  
**適用場景**: 需要快速生成符合專案規範的Vue組件時使用

#### Prompt 內容:
```
你是Vue.js前端開發專家。
請根據以下需求生成完整的Vue組件：
1. 組件名稱: [組件名稱]
2. 功能需求: [具體功能描述]
3. 技術要求: 
   - 使用Vue 3 Composition API
   - 支援TypeScript
   - 包含響應式設計
   - 遵循ESLint規範
4. 輸出內容:
   - 完整的.vue檔案
   - props定義和型別檢查
   - 事件處理邏輯
   - CSS樣式（使用scoped）
   - 必要的註解說明
```

#### 使用說明:
- 將`[組件名稱]`替換為實際的組件名稱
- 將`[具體功能描述]`替換為詳細的功能需求
- 可根據專案技術棧調整Vue版本和相關工具

#### 預期輸出:
- 生成完整的Vue組件程式碼
- 包含Template、Script、Style三個部分
- 符合Vue最佳實務和專案編碼規範

#### 相關標籤:
`#Vue3` `#CompositionAPI` `#TypeScript` `#組件開發`

2. 複製對應的prompt內容
