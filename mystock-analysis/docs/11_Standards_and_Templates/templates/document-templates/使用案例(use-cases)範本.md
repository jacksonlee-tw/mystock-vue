# [專案名稱] - 使用案例文檔

## 📋 系統概述
本系統用於管理公司船員的績效考核分數，支援多年度的船員考核管理，包含原始分數輸入、加扣分項目調整、分數計算及考核資料管理等完整功能。


**系統功能範圍：**
- 年度船員考核分數管理
- 船員基本資料與職級管理

**使用案例表：**
| 案例代號 | 案例名稱 | 說明 |
|---------|----------|------|
| UC-001 | 發起煤炭統購需求 | 當系統偵測煤炭安全庫存低於預警值，採購經辦人員可啟動統購需求流程，設定採購項目、數量並發送採購規範至相關部門。 |
| UC-002 | 統購比價與議價 | 收集供應商報價，於比價平台進行價格比較，必要時重新議價以獲取最佳採購方案。 |
| UC-003 | 確定需求規格與測算價格條件 | 廠總與財務部確認煤炭需求規格及數量，並測算價格條件，包括成本與匯率評估，作為決標依據。 |
| UC-004 | 決標與SAP草案協議生成 | 完成比價與測算後，由決標負責人啟動SAP草案協議生成，並經公文簽核後自動核發至SAP系統。 |
| UC-005 | 建立與核發正式訂單 | 採購部根據已核發的草案協議建立PO與SO，輸入SAP Client並完成簽核，正式通知供應商出貨或生產。 |

## 🎯 使用案例 1: 查看歷史年度船員考核分數

### � 使用人
- KPI設定中的考核類別為公司, 所設定的考核單位 負責及有權限

### ✅ 前提條件
- 系統已有歷史年度船員考核資料
- 使用者已登入系統
- 選擇查看過去年度（如2024年）

### 🔄 主要流程
1. 使用者選擇年度下拉選單
2. 選擇要查看的歷史年度（2024年）
3. 系統載入該年度的完整船員考核資料


### ✨ 成功後條件
- 顯示所選年度的完整船員考核分數
- 所有欄位以只讀模式呈現
- 編輯相關按鈕完全隱藏


### 🔀 替代流程
- **無歷史資料**：顯示空白表格，提示無資料
- **資料載入失敗**：顯示錯誤訊息，建議重新整理
- **部分資料缺失**：顯示現有資料，標註缺失項目

### 📊 資料展示內容
| 展示項目 | 說明 | 資料來源 |
|---------|------|----------|
| 申請單號 | 考核申請的唯一識別碼 | 系統自動生成 |
| 船員基本資料 | 姓名、工號、船名、職稱 | 船員名單匯入系統 |
| KPI指標 | 工安事故、減碳節能、泊港能效 | 公司KPI設定 |
| 原始分數 | 各KPI指標的基礎評分 | 考核輸入 |
| 調整後分數 | 加減扣分後的最終分數 | 系統計算 |
| 權重占比 | 各指標權重與公司占比 | 設定檔案 |
| 加扣分記錄 | 詳細的加扣分項目和說明 | 考核調整 |

## 🎯 使用案例 2: 設定當前年度船員考核分數

### � 使用人
- KPI設定中的考核類別為公司, 所設定的考核單位 負責及有權限

### ✅ 前提條件
- 選擇當前可編輯年度（如2025年、2026年）
- 具備船員考核分數設定權限
- 了解船員績效考核標準
- 熟悉各KPI指標評分邏輯
- 已有船員基本資料和職級分配

### 🔄 主要流程
1. 使用者選擇當前年度（2025年或2026年）
2. 系統自動進入可編輯模式
3. 檢視考核申請單號（例：20250513001）
4. 檢視船員基本資料與職級分配
5. 檢視公司KPI指標設定：
   - 📊 工安事故指標（權重45%）
   - 🌱 減碳節能指標（權重30%）
   - ⚓ 泊港能效指標（權重25%）
  
### ✨ 成功後條件
- 船員考核分數成功儲存至系統
- 原始分數與調整後分數正確計算
- 
### 🔀 替代流程
- **分數超出範圍**：系統自動調整為-200或100
- **必填欄位空白**：顯示驗證錯誤訊息，分數欄位預設80分
- **儲存失敗**：保留編輯內容，提示重試
- **無船員資料**：顯示空白列表

### 🔍 資料驗證規則
- **原始分數**：數值範圍-200~100，預設80分，支援10分整數調整
-
