
# 測試計劃與測試案例 - thmcpa (達航船員考評系統)

## 1. 專案簡介
- **系統名稱**: thmcpa (達航船員考評系統)
- **前端技術**: PrimeVue 3
- **後端技術**: Spring Boot 3
- **執行環境**: Docker
- **架構**: 前後端分離
- **目標**: 提供公司內部考核數據的登錄、查詢與分析。

---

## 2. 測試計劃

### 2.1 測試目標

### 2.2 測試範圍

- 後端 API 測試

- 部署測試（Docker Compose / 容器運行）
- 基本安全檢查（登入驗證、權限）

### 2.3 測試類型
- 功能測試
- 介面測試（UI）
- API 測試

- 瀏覽器 (Chrome、Firefox)
